# 网页视频流预览器

这是一个轻量级的单文件网页应用，用于预览网络摄像头或其他 HTTP 视频流地址。

## 功能

- 直接在浏览器中输入视频流地址进行预览
- 支持常见的 IP 摄像头 / MJPEG / stream 类型地址，例如 `http://192.168.1.4/stream`
- 左转 / 右转 90°
- 镜像显示
- 上下翻转
- 中英文双语界面
- 无需构建工具，直接打开 HTML 文件即可使用

## 文件说明

- `webcam-viewer.html` — 主程序
- `README.md` — 英文说明
- `README-zh-CN.md` — 中文说明
- `LICENSE` — 开源协议

## 快速使用

1. 用浏览器直接打开 `webcam-viewer.html`
2. 在输入框中填写视频流地址，例如：
   - `http://192.168.1.4/stream`
3. 点击 `加载流`
4. 使用控制按钮调整画面方向、镜像和翻转效果

## 说明

- 本项目适用于浏览器能直接访问的流地址。
- 流地址必须能从浏览器所在设备访问到。
- 如果浏览器不支持直接播放，程序会自动尝试嵌入式预览方式。
- 某些摄像头或流接口可能需要额外的跨域配置、网络权限或浏览器支持。
